# Erdős 1110 pairwise-coprime nonrepresentable integers

## AI USAGE:

The upstream exceptional-pair proof was generated by GPT-5.6 and formalized
with GPT-5.5, as disclosed by Apiros3. That work and its attribution are retained.
The all-pairs extension in this branch was developed with an AI coding assistant
and checked locally with Lean 4.32.1. It is a formalization contribution, not a
claim of authorship of Yu and Chen's published mathematics or Apiros3's proofs.

## Scope

This repository formalizes the Lean proof that the three exceptional pairs
left outside the Yu-Chen range have infinitely many pairwise-coprime
nonrepresentable integers:

- `(p,q) = (5,2)`, seed `c = 3`;
- `(p,q) = (9,2)`, seed `c = 5`;
- `(p,q) = (5,3)`, seed `c = 2`.

This is the pairwise-coprime strengthening, not the older ordinary infinitude
statement. Erdős-Lewin already proved that there are finitely many
nonrepresentable numbers exactly in the exceptional unordered base pair
`{p,q} = {2,3}`.

The all-pairs endpoint `Erdos1110.erdos1110_pairwise` now proves the complete
pairwise-coprime existence clause for coprime bases `p > q ≥ 2`, excluding
`(p,q) = (3,2)`, with no external Yu-Chen theorem hypothesis.
The separate natural-density question in Erdős Problem 1110 is not resolved here.

`Statement.lean` proves equivalence with the finite divisibility-antichain
representation used by Formal Conjectures and exports an infinite-set conclusion.

A self-contained human proof of the exceptional cases is in
[`docs/exceptional_cases_proof.md`](docs/exceptional_cases_proof.md).

The proof target is the sequence statement:

```lean
∃ f : Nat → Nat, Erdos1110.PairwiseCoprimeNonrepSeq p q f
```

meaning every `f n` is nonrepresentable, coprime to `p*q`, greater than `1`,
and distinct sequence terms are pairwise coprime.

## All-pairs argument and provenance

For integers below both `p^A` and `q^B`, exponent pairs lie in an `A` by `B`
rectangle. A divisibility antichain has distinct coordinates, paired in reverse
order, so its two coordinate projections determine it. Encoding the complement
of the first projection together with a shifted second projection gives at most
`choose (A+B) A` antichains, including the empty antichain.

The following integer certificates make this count smaller than any fixed
positive proportion of a sufficiently large cutoff:

- `q ≥ 4, p ≥ 5`: cutoff `2^(20t)`, rectangle `(9t,10t)`;
- `q = 3, p ≥ 7`: cutoff `2^(200t)`, rectangle `(72t,127t)`;
- `q = 2, p ≥ 11`: cutoff `2^(100t)`, rectangle `(29t,100t)`, using
  `choose (A+B) A * 3^B ≤ 4^(A+B)` and `4^129 < 2^100 * 3^100`.

Pigeonhole then produces a nonrepresentable integer in the progression
`1 + p*q*D*(k+1)`, coprime to the bases and the previous-product modulus `D`.
The existing sequence construction supplies infinitely many pairwise-coprime
witnesses. For `(4,3)`, every representable sum is 0 or 1 modulo 3, and `12D-1`
provides a fresh witness. For `(7,2)`, seed 3 uses the existing power-window
machinery. The remaining `(5,2)`, `(9,2)`, `(5,3)` cases use Apiros3's proofs.

Published range reference: Wang-Xing Yu and Yong-Gao Chen,
*On a conjecture of Erdős and Lewin*, Journal of Number Theory 238 (2022),
763–778, DOI: [10.1016/j.jnt.2021.09.018](https://doi.org/10.1016/j.jnt.2021.09.018).
The integer counting implementation here does not import that theorem as an axiom.
Upstream proof source: [Apiros3/erdos1110](https://github.com/Apiros3/erdos1110).
Public statement: [Erdős Problem 1110](https://www.erdosproblems.com/1110).
No natural-density limit theorem is claimed by this extension.
